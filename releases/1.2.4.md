# Fk-Chaoxing v1.2.4

本次更新扩展了 AI 答题能力：支持 Responses API 与思考等级配置，新增作业页面排序题、连线题的提取和自动填写，并改进填空题及运行日志体验。

## 新增

- 每个 AI 模型可分别选择 Chat Completions 或 Responses API，切换时自动调整标准请求路径，并保留自定义路径。
- 支持配置默认思考等级，也可在单次答题时临时覆盖。
- 支持提取、复制、展示及自动填写作业页面的排序题和连线题；连线题允许重复使用右侧选项。
- 增强作业页面单选题、多选题和 UEditor 填空题的自动填写能力。

## 优化与修复

- 排序题和连线题填写后校验页面选中值与答案字段；单题失败不会中断其他题目。
- 扩大弹窗运行日志区域，改进错误与不完整响应的提示。
- Responses 配置默认不发送温度参数，避免部分推理模型拒绝请求；修复 `/v1/...` 标准路径切换问题。
- 修复多个 UEditor 填空框粘贴后内容未在答题区域显示的问题，并更新字体识别库。

## 使用说明

旧模型配置继续使用 Chat Completions。保存新接口配置时会进行连接测试，可能产生模型调用费用。自动作答只填写答案，不会主动保存或提交；请在提交作业前自行核对。

相关改动见 [PR #6](https://github.com/iPycc/Fk-Chaoxing-Extension/pull/6)。
